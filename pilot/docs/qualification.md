# R1 qualification, v3

The original A/B/C packet remains in `qualification-v2.md` as historical evidence. The active first milestone is a usable authenticated GKE core release with fresh data. Existing Sites and data migration are excluded. Broader background and Memory are subsequent milestones.

Local verified evidence must remain distinct from hosted acceptance:

| Requirement | Local evidence | Hosted evidence |
| --- | --- | --- |
| Native Still creation/review and Forma edit return | Browser journey, real PG, same IDs/prose | Pending live URL |
| Consent, IAP signature, role/scope | Local signed tokens and denial tests | Pending real admitted accounts |
| Rich references, conflicts, retry receipts | Native controller + HTTP + PostgreSQL tests | Pending shared browser test |
| Sharing/viewer/revocation | Both independent signed identities and one signed operator with two app principals; exact event IDs, denied reads/writes | Pending two controlled app users behind one real IAP operator |
| Offered source deletion | Physical current event/draft/operation body erasure and reference guards | Pending hosted repetition |
| Application restart persistence | Local Node restart; PostgreSQL retained | Pending pod restart |
| Deployment | Images, native checks, fresh schema/runtime-role container checks | Pending GitHub/infra/auth inputs and rollout |

Only plain authored Idea/Project sources are offered for permanent deletion. Document-only deletion, uploads, derived objects, model attempts and search stores are disabled. Applied creation drafts are reduced to scope metadata; private creation prose is not retained in completed receipts. Active drafts remain encrypted until discarded, affected-source deletion or test teardown. The test is explicitly open-ended; teardown is an owner action, not an automatic cloud cost cap.

Unknown APIs/pages return an error. R1 UI hides unrelated generation, delivery, Memory and broader workspace controls; direct requests remain denied at the server. Model-free manual creation is real native behavior, not simulated provider validation. No frozen qualification packet is retuned.

Before claiming release: record commit/digests, actual origin and IAP audience, backend protection and admissions, namespace/PVC/bucket identities, deployment revision, same-ID browser journey, stale-edit recovery, second-principal revocation, current-body erasure, restart and one redeploy. User review/acceptance is a separate report checkpoint.
