# Implemented prospective contract — v1

This replaces the design-only status in the accepted [4db8cca5 archive](archive/4db8cca5/dependency-design.md).

1. `readWorkspaceSourceCensus` extends the canonical profile reader with an optional pre-serialization custody observation and `EventReadProof`. It uses the same workspace profile as ordinary source resolution, a complete count, bounded rows and a final exact-row proof. It does not change the administrator full-stream diagnostic.
2. `createCreativeEventFold` optionally reports eligibility and resolved project/document bindings **where existing semantics execute**. The complete row census is preserved. Unknown or unsupported semantics cannot certify text-only input; normal fold/admission behavior is unchanged.
3. `readSourceAuthority` verifies original private/public envelope agreement, ownership, stream, event version, scope, project/document/idea incarnation, canonical projection, Memory/rights/provenance exclusions and complete dependency lifetimes. `requalifySourceAuthority` runs the real producer again and requires exact receipt equality. Hash equality alone is never authority.
4. During the existing authorized preflight, `sourceAdvisoryWitness` receives the actual `sourceAdvisoryInputs` array through an isolated observer. Both original private evidence envelopes carry identical receipt, immutable original times and exact positional manifest. Readiness carries only server-owned metadata/ref links. Witness/observer/storage failure cannot suppress dispatch or replace the existing verdict. Cache adoption copies the original witness identity and cannot promote an unsupported selection.
5. One hosted selected GET qualifies original/selected preflight rows and at most two body refs; exact envelope/body hashes, operation identity, input manifest and result cardinality; then complete current source and private/native custody. A final shared read-only batch rechecks all authority. Minimum immutable deadlines and environment/database identity are checked before response return.
6. Still's image review disclosure performs this GET only. Raw strings use escaped text bindings and are removed locally on disconnect or expiry. Acknowledgement remains the existing explicit action.

Bounds: complete workspace profile ≤128 dependencies, full snapshot <28,000 UTF-16 units, per-row public/private JSON ≤65,536 UTF-8 bytes and bounded accumulated row metadata. Existing isolated-fact truncation is disclosed, not changed. All non-plain provenance/lifetime semantics fail closed. Whole-workspace census is intentionally conservative; larger/richer histories need a separate versioned resolver contract, not a route-local event subset.

Authored sidecars have no expires_at field. Their declared lifecycle ends at erasure, redaction or changed scope/custody/content; the origin preflight additionally caps access. Rights-bearing lifetime contracts are excluded in full, including prior values and inactive facts. Neither expired preflights nor missing origin rows are reconstructed.

The moderation API associates results by array position. A semantically reordered but structurally valid provider response cannot be detected without echoed input identities. No causal-span or classifier-quality claim is made.
