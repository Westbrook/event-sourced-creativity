## Exact support

Personal hosted creator/admin, self-paid Still manual `generate`, with a complete canonical workspace census of at most 128 dependencies and a full source snapshot strictly below 28,000 JavaScript UTF-16 code units. A real ordinary Still-shaped project/document/idea with private custody, ordinary requested/completed preflight telemetry and unrelated manual project history qualifies. Genuine cache adoption retains the original preflight, request, body pair, source authority and access deadline.

The v1 census conservatively includes **every workspace-profile row**, including unrelated manual history and original project/document membership and lifecycle. Eligibility is declared inside the existing reducer cases, not by a second event reader's type allowlist. Supported history consists of unique explicit project/document/idea origins, project open/rename/state, document open/rename/remove/restore, and simple idea rename/property/weight/lock/remove/restore operations. Normal Still `project_owned` ideas are supported. Supported text properties are text, instruction, value, label, description, subtype, intent, authored authority and numeric weight; position edits are supported. The initial block-type set is explicitly closed in the canonical reducer.

The snapshot input remains untruncated. Isolated fact inputs retain the existing 6,000-unit limit and first-24 projection; the witness records the actual positional mapping, truncation, UTF-16/UTF-8 lengths and hashes. Nothing changes the moderation input array, model, threshold, provider request count, verdict, aggregate review, admission or acknowledgement behavior.

## Unavailable cases

References/3D, derived or rights-bearing inputs (including cleared historical rights), Memory, native Output/durable-slot context, governed/sponsored/billing-delegated/workflow context, Canvas, narrowed character context, preview references and managed production are unavailable. The v1 receipt also conservatively declines relationships, attachments/rehome/library transitions, collections, preferences, compensation/causal provenance, other unsupported reducer semantics, unknown properties and future events. Unsupported history anywhere in the retained census can make a document unavailable. This is a narrow prospective contract, not a general workspace evidence reader.

Missing, incomplete, redacted, deleted, substituted, foreign, scoped, expired or changed source/body/witness records return metadata only. Old preflights are never backfilled. The original preflight row must still exist: an upsert that replaces it makes its later adopter unavailable. Longer body retention or an adopter's later expiry cannot extend the immutable origin deadline.

Authored event sidecars have no schema-level expiry. Their explicit v1 lifetime is retention until deletion, redaction, or any source/custody/scope change, capped for inspection by the original preflight/witness deadline. Any payload carrying a separate lifetime or rights contract is outside this v1 schema; it is not silently treated as perpetual.

## Read boundary and verification

The selected GET accepts no arbitrary content references and reads at most the two server-owned moderation bodies. It checks exact envelope/body digests, original/adopter identity, requested/returned identity and positional input/result association. Invalid or cardinality-mismatched provider results have unknown flags/categories/scores; valid empty categories and absent scores remain distinct.

The final read-only batch rechecks the principal, exact original/selected rows, complete canonical source census, scope, native/Memory exclusions and exact body bytes. Database/configuration identity and the minimum access deadline are checked immediately before returning. The route runs before initializers and is excluded from post-response retention scheduling. Tests count SQL mutation/initializer attempts, provider attempts, background actions and total database changes on success and denial.
