# N7 selected workspace eligibility diagnostic

`GET /api/source-advisory-eligibility?documentId=<existing selection>` accepts exactly one opaque document selector. Hosted identity and the existing read-only principal helper derive the personal owner and creative stream. Impersonation/project delegation cookies, configured pilot context, arbitrary selectors, non-GET requests and absent/foreign selected document origins refuse. The response is private/no-store and the route precedes account/schema initializers and is excluded from retention scheduling.

Stage1 is SQL-only metadata projection. It uses `eventProfilePredicate('workspace')`, shared with the existing canonical reader and N6 census, including excluded telemetry/phantom predicates. SQL returns one row of numeric measurements plus a closed kind/actor-class histogram: no payload/private_json, raw arbitrary actor/kind names, row identifiers, unrelated identities, content references or source text. Kind labels are a display vocabulary using existing model/privacy catalogs and known ordinary-history names; they never control membership or eligibility. Unknown types/actors are coalesced and never dropped.

The SQL stream scan has a separate 100,000-row observation work bound, counting physical stream rows including telemetry. At saturation, the 100,001st row establishes incompleteness: count is null, a lower bound is labeled, and no source is hydrated. Complete metadata reports the exact canonical dependency count and public/private payload byte footprint/largest cell. Applicable private-custody, redaction, envelope header binding and event/resource/organization scope exclusions are counted. This is aggregate metadata, not semantic validation or exact body equality. The same aggregate and principal are rechecked before returning; failures discard the observation.

The N6 limits remain 128 dependencies, 65,536 UTF-8 bytes per transported cell, 512,000 UTF-16 units for complete serialized census rows, and snapshot strictly below 28,000 UTF-16 units. SQL codepoint counts are only a lower bound for the serialized UTF-16 census size; exceeding512,000 proves overflow, whereas fitting this lower bound does not prove admission. Stage2 applies the exact existing row bound. UTF-8 footprint alone is not treated as a UTF-16 capacity predicate.

Only complete, in-bound metadata with no measured custody/scope exclusions reaches Stage2. The existing `readSourceAuthority` internally hydrates the bounded current census, uses the canonical resolver/ordinary-history/lifetime/provenance guards and exact private body proof, and qualifies the selected source. An added SQL cardinality gate ensures even a concurrent growth past128 returns no hydrated body rows. No historical moderation or output content is dereferenced. Canonical optional semantic observations report closed unsupported-kind counts; unknown names remain coalesced. Source failures do not weaken admission or modify events.

Qualified responses contain only receipt version, document revision, source/census digests, dependency count, snapshot UTF-16/UTF-8 lengths and positional input index/kind/source-index/truncation/length/digest metadata. Construction uses the actual `sourceAdvisoryInputs`; block IDs and source text are omitted. No preflight, witness, timestamped authority renewal or advisory capture is minted. The final read-only batch repeats the exact canonical census/body and principal proofs as well as the aggregate; database and relevant configuration/credential reference identity are checked before return.

Configuration reports the existing moderation contract endpoint/model and configured booleans. Actual provider credential and project identity remain unknown; raw secrets are not fingerprinted or displayed. No H5 planner account-binding contract is imported. `metadataMeasured`, `sourceQualified`, `observationReady:false` and `executionAuthorized:false` remain distinct. Even an eligible source requires later current revision/configuration/credential and price checks plus separate user approval before any preflight.

No broad UI or new migration is needed. This is a private diagnostic JSON result, delivered through a compact local review receipt. It does not certify classifier quality, mature-workspace support or another media route. The older administrator full-stream source diagnostic and admitted-job reader remain unchanged.
