# Original image-attempt evidence inspection

The owner can now inspect one retained ordinary image attempt at `/generation-evidence?documentId=<document>&requestedSequence=<GenerationRequested sequence>`. The JSON equivalent is `/api/generation-evidence`; the page also offers a private download. This is a separate observational handler, because generic document-job polling can perform recovery or reconciliation.

The handler requires the existing hosted personal principal, account policy and consent. It selects exactly one terminal, unexpired owned `generate` job by its original request event, document, stream and correlation. Project, impersonation, Memory-marked, sponsored and native Output custody cannot use this route. Referenced private content is restricted to the original checkpoint and selected generation events; callers cannot supply arbitrary content IDs. Ownership, redaction, expiry, project containment and the existing certified Memory exclusion remain mandatory. Custody and bytes are checked again before returning. Nothing initializes schema/accounts, sweeps retention, repairs jobs, changes charges, dispatches a queue or calls a provider.

Returned job/event strings and content strings preserve stored bytes. Content includes its original timestamps, digest and reference provenance. Missing or inaccessible records are listed explicitly. A retained compiled snapshot is not automatically the full original authored source; the reader never recreates missing input. Application usage/settlement is not independent verified incurred charge, and current environment configuration cannot establish an original account/payer/region/credential binding.

Validation extends the existing isolated-schema source/compiled-Worker regression with owner/authentication checks, read-only database and background-work assertions, project/content ownership refusal, expiry/redaction, Memory and native Output rejection, and certified-isolation failure. Its image mock now supplies the streamed completion already requested by current main. All provider activity in this regression is mocked.
