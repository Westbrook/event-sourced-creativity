# Ideogram 4 adapter campaign 3

## Objective

Find the first adapter that passes the unchanged `canvas-image-corpus-v6` qualification. Run no more than ten immutable candidates (`v31`–`v40`) and stop immediately after the first complete 50-case pass.

## Narrow hypothesis

Campaign 2 proved that the expanded route can deliver reliably and preserve reference images: `v30` completed 7/7 micro requests, produced 6/7 usable images, and made both reference cases usable. Its remaining misses were exact composition, the coincident XML technique floor, and a 1.143-point instruction-adherence gap.

Campaign 3 therefore keeps the reliable expanded route and changes only semantic priority:

- promote exact composition and edge-only framing before descriptive prose;
- convert hands-only framing into an explicit exclusion of faces, heads, torsos, and full bodies;
- require subject, setting, composition, and materials to pass one jointly visible checklist;
- normalize every canonical source technique into the same provider-facing visual contract;
- compare Large and Medium expansion only after the semantic contract changes;
- retain the reference strengths that already made both micro reference studies usable.

## Progressive funnel

1. Validate every candidate against all 50 request contracts without a provider call.
2. Render the same seven-case micro screen.
3. Advance only a passing candidate to the fixed 15-case sentinel.
4. Advance only a passing sentinel to the complete 50-case qualification.
5. Stop at the first full pass or after ten candidates.

No micro or sentinel result can approve the adapter. Frozen OpenAI baseline pixels are reused after corpus-hash verification.

## Candidate order

- `v31`: complete literal acceptance contract.
- `v32`: composition-first contract.
- `v33`: numbered semantic checklist.
- `v34`: compact literal prompt.
- `v35`: constraints-first prompt.
- `v36`: literal contract with Medium expansion.
- `v37`: composition-first with Medium expansion.
- `v38`: literal contract retaining more composition-reference geometry.
- `v39`: checklist with slightly more source geometry.
- `v40`: final literal contract with fully disposable inspiration pixels.

## Authorization and evidence

The campaign requires the exact campaign-3 approval token, enforces the ten-cycle ceiling, checkpoints every request, and retains prompts, revisions, pixels, evaluator fingerprints, latency, cost, and provider request IDs under an immutable version directory. Successful-image costs remain separate from failed attempts, moderation, and evaluator charges.
