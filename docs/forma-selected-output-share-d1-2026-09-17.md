# Selected-output sharing database qualification

The first selected-output sharing implementation passed native SQLite tests but failed the target database's expression-depth limit. Supplemental qualification preserved the exact SQL and synthetic bindings: twelve statements failed actual local workerd/D1 at expression depth 100. A thirteenth statement exceeded the required 32-function-argument compatibility limit; this local workerd version accepted that original 40-argument JSON expression. These are distinct findings.

The corrective implementation keeps complete native custody, current principal policy, event snapshots, private bytes, source expiry, completed actor-paid provenance, optional schema state and exact share-row proofs. Each full proof becomes a sibling MATERIALIZED relation. The final read or conditional write requires every relation in one database statement. No authorization predicate is dropped, and no write is separated from its current proof.

The share-only native custody adapter now returns a complete SELECT instead of wrapping the original final read in another scalar EXISTS and CASE. The shared native final guard and ordinary retained-output handler are unchanged. Provenance JSON uses bounded json_object and json_set expressions; it preserves explicit null fields, key order and exact serialized witness bytes.

Qualification must include the required limits together: expression depth 100, at most 32 function arguments, 100 bound parameters and 100,000 SQL bytes. An actual local workerd/D1 bridge executes unchanged SQL, bindings and batch boundaries from the production prepare, commit, duplicate-approval replay, read, revoke and confirmed personal-erasure functions over disposable synthetic data. The functions execute in Node; this is database-backend qualification, not a bundled Worker HTTP-route test. EXPLAIN alone is insufficient execution evidence. Optional sponsor-table states and configured pilot access must remain covered. No provider, private media, real share or financial operation belongs to this qualification.

Creation remains the explicit false dispatcher constant, and the separately rejected automatic retention scheduler patch remains unapplied. This correction changes query representation, not publication authority, retention policy, site audience or activation. Final test counts and exact source hashes belong to the accompanying sealed evidence packet.
