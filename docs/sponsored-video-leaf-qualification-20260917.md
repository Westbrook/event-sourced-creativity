# Inert Video sponsor contract and native evidence

This six-file increment adds a closed `canonical-owned-still-video@1` review template and an actual native evidence reader. It adds no shared sponsor-policy branch, route, campaign, approval, grant, financial mutation or activation. Shared policy V7 is reserved for later work; the leaf's version 1 does not implement that policy.

The native family remains one owned ordinary still, one four-second silent 480p clip, OpenAI planning and fal Seedance 2.0 rendering. Both current frame orientations remain available. Legacy frame dimensions denote orientation; the sponsor recipe uses zero physical width/height rather than claiming 720p output. The exact source-dependent native planner wire/quote, original operation identity, source graph, still hash, rights, canonical principal, latest plan and private quote bodies are revalidated. A matching template or returned DTO grants no authority.

The evidence reader captures caller inputs before its first yield. A fresh native preflight retains the existing original-proof capability, and its complete source/rights predicates join the final read batch. The original Request, DB, media binding, model/provider settings, keys and source remain current across asynchronous work. Abort/deadline checks fence the first read, subsequent leaf-owned work and return. Already dispatched native DB reads cannot be cancelled by this helper; their results cannot authorize a late return or another leaf-owned read.

Native source custody requires HEAD, provenance HEAD, GET and final HEAD. The local read adapter permits exactly one source key, at most three HEADs and one GET, a 30 MiB source-byte ceiling, 65,536 chunks and one 30-second overall lifetime. The source cap is not an aggregate-memory measurement: copied chunks, concatenation and the native reader introduce additional buffers. This is an inert evidence-work bound, not approved sponsor resource funding. Full campaign resource terms, resource accounting and activation remain later dependencies.

The reviewed transfer envelope includes the native transport limits and the existing requested 24-hour fal staging lifetime. The eventual fal request body is deliberately not invented at preflight: the adapted direction follows planning and the final image URL follows staging. Later execution must preserve the real native paid-wire checkpoint, exact provider call ledger and original payer settlement.

Qualification uses real imported production modules against synthetic canonical intake, native SAVE/CONFIRM/preflight and a disposable in-memory original image. Pure contract tests separately construct actual closed native offers. Tests enforce no network/provider calls, no real private assets, no generated results or media writes, no new sponsor schema and no admission/financial state. Strict local SQLite checks are distinguished from Node-hosted production modules against actual local workerd D1. This does not repeat or replace the accepted ordinary live Video journey.

Historical failures are retained in the external evidence packet: an initial type-check failure while the new modules were incomplete; two test-fixture mistakes (a nonexistent fixture column and an incomplete expected error family); a template/test timing mismatch while the transport field was added; and sandbox denial of a loopback listener. Independent review also identified and verified repairs for a deferred first capture, an unobserved race rejection, and a missing immediate pre-dispatch lifetime check. None is erased by the final qualification.

Later work is explicitly separate: sponsor actor consent and payer approval; shared Video policy/admission/financial profile and exact replay; finite reference/intake/quote/status/result/history/media/edit/restore/recovery allowances; a sponsor-specific driver; approved identity/campaign terms; and relevant physical-device checks. Ordinary marked-sponsor routes remain refused. Native Video Output Requirements adoption remains unsupported. Public sharing changes and the separately deferred automatic server-owned generation architecture are not included.

Final qualification passed 11 pure contract tests and 16 native evidence tests. The actual local workerd D1 case ran the production functions from Node against workerd D1: 95 SELECT statements, 21 SQL shapes, maximum 30 bindings and 18,185 SQL bytes; two positive source reads and a late original-source redaction denial. It made no provider/outbound request or media write. The full native run also exercised an actual 30-second stalled-stream deadline. This is not a deployed Worker HTTP test or a production/physical-device claim. Source hashes, logs, strict SQLite limits and detailed D1 observations are recorded in the sealed external evidence manifest accompanying this commit.
