# Private Library and Canvas opening history — 2026-09-21

## Implemented

The actual visible Library and selected Canvas now report one resource opening.
Only an already explicitly enrolled, currently authorized resource with learning
enabled may retain it. The selected or linked Document is never used as a stand-in
resource, enrollment, source body or permission. Settings refresh, focus, locale
change and enrollment do not retry or manufacture another opening. A hidden,
detached, impersonated or privacy-suspended surface cannot dispatch a new receipt.

These are actor-private D1 observation receipts, not authored events or original
human preference evidence. No resource prose, linked content, inspected-content
version, reading duration or comprehension is claimed. The real Memory controls
show separately labeled7/30-day opening counts beside existing action counts,
in English, French, Arabic and Japanese.

Native admission replays resource custody, current rights, permission epoch,
exact consent/revision, source frontier and schema in the receipt transaction.
An opaque per-opening ID deduplicates uncertain repeated submissions. There is
no automatic retry; a lost acknowledgement is not called a failed write. Limits
are128 receipts per resource per UTC day,2,048 retained and256 read. No model,
financial ledger, authored source event or nightly capture cursor is changed.

Additive0069 contains private opening receipts, expiry indexing, immutable
identity and settings-replacement retirement. Forgetting or deleting the actor's
resource enrollment cascades to its receipts. Personal erasure preserves
organization custody. Restored old-revision receipts are not read under renewed
consent. Source-free expiry maintenance runs independently of rollout/scheduling.
The exact old0067 schema remains supported for existing controls and forgetting;
opening collection stays disabled there. No migration runs in an HTTP request.
