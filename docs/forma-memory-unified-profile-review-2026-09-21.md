# Unified current-profile review — 2026-09-21

Implemented locally; not deployed, enrolled or provider-qualified.

## Actual integration

The real Memory panel now exposes one actor-private catalog over separately
governed, automatically derived document profile projections. Organization,
owner, project and document identities stay explicit. Listing returns control
metadata only; it does not read source prose, grant access, purchase processing,
start a model, enroll resources or combine confidential partitions.

An explicit inspection uses the original native result/source reader plus a
current-head predicate in its final atomic proof. The latest completed profile
job is authoritative for selection. A withdrawn/expired head is not replaced
with an older interpretation. Completion metadata participates even if a result
body is unavailable. Existing historical review remains deliberately available
under its separate, non-current contract.

The view shows tentative source-backed claims, original quotes, counterevidence
and independently checked user corrections. Corrected/suppressed lineages cannot
reappear as current claims. New independent originals can support a later claim;
that does not erase or supersede the user's retained correction. A control change
between the controls read and final result inspection rejects the combined view.

English, French, Arabic and Japanese copy is provided. Private text is literal,
never HTML. Source/account/route/locale changes, privacy mutations, blur, page hide,
expiry and disconnection clear it. Focus never resurrects it. Catalogs are bounded
to 16 entries with explicit paging; one original 30-second wall/monotonic lifetime
covers delivery. No private browser storage or automatic catalog polling is added.
