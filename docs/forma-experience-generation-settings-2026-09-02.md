# Experience generation settings: qualification boundary

This additive slice compiles a registered, retained experience plan to a pure settings intent. It does not enable generation, qualify an adapter, create a native job, or alter any Worker route. All eight outputs remain subject to their separate execution and result qualification.

## Contract

`src/experiences/generation.ts` reconstructs the complete current registered plan for the server-supplied principal before accepting it. Comparison covers the release, authored values and provenance, canonical identities, bindings and native events; a caller-recomputed hash is insufficient. Input is validated without invoking getters and snapshotted before the first asynchronous boundary. The returned contract is recursively frozen and carries `qualification: "settings-only"`.

The deterministic `generationIntentId` identifies this owner, retained draft, release and authored intent. It is **not a native job ID or an idempotency guarantee for provider execution**. Existing native Output authorization remains responsible for actual grant, slot, job and reservation identities. A minimal embedded identity can be compared with a server-recompiled contract; this comparison proves neither current source custody nor execution authority.

| Output | Settings intent |
| --- | --- |
| Image | Manual generation; native default prompt technique |
| Short story | One manual `short_story` artifact |
| Scene | One manual visual Scene; no manufactured Scene approval |
| Slides | One presentation with an exact five-slide policy; faithful fidelity |
| Storyboard | Four frames |
| Video | Four seconds; native default silent mode |
| Audio | Original instrumental music; score role, standalone destination; no invented duration or selected model |
| 3D model | Exact authored prompt in registered decision/field order; unchanged native defaults, GLB, no references; native prompt validation |

No consent, budget acknowledgment, provider route, pricing version, source snapshot, execution proof, native job ID or reservation is synthesized. The server must separately establish retained custody and unchanged canonical source at the actual admission boundary. The compiler is not connected to the public entry or an endpoint in this slice.

## Execution direction

The deployment owner requires reuse of the existing native Output slot/grant/descriptor/re-preflight/per-call-guard machinery. The ad-hoc job receipt is not a substitute for a reviewed route or an enforced operation ceiling. Native Output currently qualifies Image, Slides and 3D only. Short story, Scene, Storyboard, Video and Audio require separate accepted capability extensions; mapping their settings here never removes the unsupported-family guard.

Only native-enforced limits may be described as maxima. Estimated cost, application-enforced allowance and provider hard caps must remain distinct. Native Scene approval is separately bound to its exact request, source and authority; this contract supplies no replacement approval. Recovery must retain the original paid operation and never create a replacement purchase implicitly.
