# Memory-assisted text edit review — 2026-09-20

## Delivered scope

The actual consent-bound specialist consumer now retains eligible text-edit
suggestions inside its existing private, ancestry-dependent result. Both the
Document Assistant and embedded Chat Studio guidance show the approved source
excerpt and suggested replacement. The record binds the execution, turn,
project, document, source hash, original language, block, `text` field and block
revision. The excerpt is explicitly historical; it is not a claim that the
current field still has that value.

This is **review-only**, not completed creative editing. There is no Apply,
copy-to-context, autocomplete acceptance, generation or new purchase control.
No actionable proposal or document event is created. Ordinary specialist actions
are unchanged; Memory results still have empty action arrays.

## Privacy and validation

- Only unambiguous, editable, provider-eligible text targets are included.
  Locked, protected, immutable, prohibited, restricted, unknown and duplicate
  targets are excluded; create/remove/relation actions are not reinterpreted.
- Presentation data has an exact bounded schema. Foreign resource/execution,
  source hash, language, field and revision data cannot become a review. The
  native retained-result reader also rebuilds eligibility against the approved
  context, not just a matching source hash.
- Reviews share the existing result copy's source/target consent, lifetime,
  native original-source replay, user controls and retirement inverse. No new
  schema, source authority, retention period or provider operation is added.
- Withdrawal erases dependent private copies without resetting accounted usage.
  Negative ancestry still denies disclosure after an invalid restore retypes
  previously retired bytes; raw database restoration is not an authorized writer.
- Blur, expiry, navigation and privacy withdrawal clear preview bytes with the
  existing private review. A pending read, quote or historical feed can discover Memory provenance
  late, so its presentation epoch is now retired too. This does not cancel or
  refund a submitted provider operation. Unsent ordinary drafts remain local.
- English, French, Arabic and Japanese controls identify review-only suggestions.
  Lit text interpolation keeps script-like content literal. No draft telemetry,
  real provider call, real-user enrollment or hosted change occurred.
