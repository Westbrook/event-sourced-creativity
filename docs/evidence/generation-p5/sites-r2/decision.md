## What changed in this assessment

Physical DB/bucket IDs and an external SQL executor are not intrinsically required. Site/version/environment receipts plus durable compiled dataset markers, exact transaction outcomes and original object hashes can demonstrate the logical behavior we need, with explicit limits. Sites already supports schema-only migrations, authenticated Worker routes, D1 batch calls, R2 bindings and read-only observability. N10H supplies a real hosted precedent; it is not a P5 qualification result.

Read-only inspection confirms N10H's original Site remains version 1 and its stored run is disabled with report removed. The original importer, proof and cleanup were not invoked. A successor there is an explicit alternative: preserve its old migration/tombstone, prepare a separate P5 finite fixture, add newly approved R2 and narrowly selected schema, and disclose costs. It would test another Site's synthetic runtime; Forma's actual identity/holds/schema/custody would still need separate evidence. Full-baseline local comparison finds 26 shared schema objects identical and 766 additional objects; that large set is not an approved or minimal migration.

For the **selected Forma target**, the missing supported operation is isolating canonical application authority tables for a fixture while preserving ordinary production bindings. P5's existing guards read users/budgets/holds and exact schema; merely adding key prefixes or mocking schema replies would not prove the unchanged adapter. All exposed deployment URLs are production, and the manifest/native API provides no per-version disposable DB/environment operation. This is a demonstrated control-surface gap, not proof of a fundamental Sites limitation.

A generic SQL/diagnostic endpoint is neither needed nor proposed. Once an isolated path exists, a fixed-function schema preflight, pinned importer, exact finite cases and cleanup can be compiled and sealed using the N10H method. No executable fixture is claimed ready while that essential binding path is unresolved.
