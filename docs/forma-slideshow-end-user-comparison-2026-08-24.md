The updated pipeline now:

1. Detects and preserves all 12 authored slide positions, supports explicit
   managed requests up to 100 slides, and exposes accurate 23-slide planning:
   three batches, three initial provider requests, up to 12 bounded requests,
   and a $3 application-side ceiling.
2. Synchronizes the visible manual count selector with the actual 12-slide plan;
   an end user verified that both the selected option and predicted count now
   read 12. Requests above 100 are visibly rejected and cannot be submitted.
3. Protects all six source-authored scores, exact/display semantics, complete
   stakeholder quotations, distinct named speakers and roles, all four device
   postures, five destinations, three authoring modes, and phase-bound roadmap
   durations.
4. Rejects contradictory score labels in speaker notes and Markdown, swapped
   roadmap phases, altered speaker names, omitted postures, missing score rows,
   and forged score-bar weights.
5. Derives 100-point score-bar geometry from trusted numeric values across native
   HTML, searchable PDF, and editable PowerPoint; qualitative nonnumeric visual
   weights remain unchanged.
6. Preserves an explicitly authored safe typeface through the canonical model,
   browser rendering, editable PowerPoint text runs, and PowerPoint theme.
   Unsupported embedded/custom PDF fonts are not silently claimed.
7. Enforces a minimum **12-point** visible PowerPoint type size. A representative
   23-slide Forma export contains 442 editable shapes, 24 real connectors, 190
   meaningful accessibility descriptions, 24 complete score bars, 23 sourced
   presenter-note sections, and no leaked durable source identifiers.
8. Gives the submitting actor explicit access to project-scoped private generation
   inputs without broadening shared job lists, collaborator responses, event
   hydration, or shared caches. One atomic read checks the exact actor, owner,
   organization, project, document, job, audit anchor, governed retention, active
   consent/membership, and live nonrevoked project session. Mid-read revocation
   and incorrect retention classification fail closed.
9. Applies conservative request-by-request spending preflight using serialized
   request bytes, bounded output tokens, verified model pricing, already charged
   usage, and the job's reserved maximum. Unknown model pricing fails closed;
   bounded repairs are rejected before submission if they would exceed the cap.
10. Never automatically replays an ambiguous paid OpenAI Responses POST.
    A manually requested 12-slide Terra generation is limited to one initial
    request plus at most one bounded repair and a **$1** application-enforced
    ceiling. This is deliberately not described as a provider-enforced cap.

## Deferred work and rationale

**True embedded Office charts and images remain intentionally deferred in
Forma's native exporter.** Existing bar charts, scorecards, matrices, quote
cards, roadmap nodes, and architecture diagrams are already independently
editable PowerPoint geometry, including genuine connectors and alternative
descriptions. The user's existing 23-slide reference itself contains no Office
charts or images. Excel-backed chart editing would require embedded binary
workbooks, duplicated cached source data, additional relationships, new privacy
scrubbing, and a significant change to the current bounded XML-only archive.
Images would additionally require authorized source assets or separately
approved external generation. Neither change is justified merely to inflate an
editability metric.

**PDF custom font embedding remains deferred.** The browser and PowerPoint
honor the safe authored typeface, while the accessible searchable PDF continues
to use its interoperable built-in font behavior. Embedding arbitrary authored
fonts would require vetted, licensed font binaries and substantially broader PDF
generation changes.

**A provider-enforced dollar cap is not claimed.** The provider API does not
offer the relevant request-level guarantee. Forma instead enforces a
conservative application-side ceiling before every initial, repair, and managed
batch request; actual provider receipts and settlement remain truthful.

**New live generation remains pending explicit browser confirmation.** The
allowed action is exactly one manual, faithful, document-styled, 12-slide
OpenAI `gpt-5.6-terra` generation, transmitting the authorized source document,
with at most two provider submissions and a $1 ceiling. Existing artifacts and
local/mock verification are never mislabeled as that fresh paid run.
