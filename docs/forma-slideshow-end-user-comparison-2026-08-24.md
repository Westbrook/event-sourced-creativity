## Deferred work and why further implementation is not justified

**True native Office Chart/Table/Image objects: defer intentionally.** The
final Forma deck contains genuine independently editable PowerPoint shapes and
connectors, but no `ppt/charts` parts, `a:tbl` table objects, embedded image
parts, or embedded workbook. The independent comparator demonstrates that a
workbook-free literal-cache chart is technically possible. However, Forma's
actual PowerPoint importer currently ignores chart relationships: all six
protected chart scores disappear when that comparator is re-imported, while
every score and slide-9 capability survives the final native shape-based
export/import round trip. Delivering chart objects responsibly would therefore
require a coordinated exporter **and importer** design, relationship traversal,
editable-cache/workbook policy, duplicated-source privacy scrubbing, security
limits, accessibility semantics, and regression coverage. Raster images would
add separate licensed or user-authorized source requirements. The external
23-slide reference itself contains no native charts or images. Implementing
only a chart count now would worsen genuine user-visible round-trip fidelity
while offering no improvement to the independently accepted **100 / 100** deck.

**Custom embedded PDF fonts: defer intentionally.** Safe authored typography is
preserved in the native browser presentation, editable PowerPoint runs, and
PowerPoint theme. Arbitrary embedded PDF fonts require vetted redistributable
font binaries, licensing, Unicode subset and text-extraction support, and a
broader searchable/accessibility-preserving PDF architecture. No authorized
font asset or user-visible failure warrants that expansion.

**Provider-enforced spending ceilings: do not misrepresent or implement an
unavailable guarantee.** Forma's bound is an application-enforced conservative
preflight before each priced initial, repair, and managed request; actual
provider receipts and settlement remain visible. A provider-enforced per-request
or per-job dollar cap is not available through this application contract.

**Broader access to full failed provider prompts: defer for privacy.** The
submitting actor already receives the exact governed source snapshot, source
transmission state, provider-call counts, final validation details, and settled
cost through a deliberately narrow actor-private receipt. Sharing complete
failed provider prompts across project collaborators would unnecessarily widen
sensitive source exposure and weaken the existing exact-actor, project,
membership, retention, and live-session authorization contract.

**Additional paid generations: stop.** The user's limit authorizes at most
10 iteration generations; the third newly authorized iteration already passes
all independently verified source, accessibility, privacy, export, and
end-user acceptance gates. A fourth paid generation would disclose the same
document again, consume additional tokens and money, and introduce creative
variation without an identified unresolved acceptance failure.
