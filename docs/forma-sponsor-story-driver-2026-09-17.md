## Original intent, authority and recovery

The issuer captures the Request, environment, DB, actor, personal scope, source context/assertions, current principal and provider configuration in an opaque WeakMap authority. It uses the V4-only approved-campaign loader. Native retained plan/quote bytes, selected narrative target, source and requirement digests, current actor/payer authority and explicit reviewed template are checked before issuance. Grant, bounded `issuance` resource receipt and immutable issuer receipt commit in one existing native transaction.

The driver obtains its own native preflight and retains immutable `preflight`, `authorize`, and `run` stage commands. Resource V1 continues to count existing-Document `text-intake`, `preflight` and `issuance`; it does not authorize initial sponsored draft storage. Campaign and actor counters survive failed native admission and terminal jobs. Exact replay never changes timestamps, grant identity, source, quote, maximum cost or resource receipts.

A preflight ticket that committed without a durable native receipt remains unknown; another request cannot repeat that protected work. An intake-only receipt may claim a still-absent preflight stage once. Lost native preflight, authorization or Run acknowledgments recover the original recorded command and job.

There is an explicit distinction after native authorization commits: the owner stream has advanced, so fresh admission against the old `expectedRevision` must refuse. The issuer instead verifies the exact persisted sponsored authorization envelope and command digest, approval/issuance/resource/consumption lineage, plan, preflight, target, original slot, provider/model, native ceiling and actor-owned Story job. It returns `kind:"admitted"` and the original native receipt, with **no admission or execution authority**. The driver can record its still-absent Run stage from that receipt, then must obtain fresh B execution authority. Mutated command, slot or consumption lineage refuses.

New driver transitions check the original DB and request cancellation before and after awaits. The final metadata read repeats current campaign/source/intent authority in its guarded batch and checks the earliest authority deadline again after the await. Detached `waitUntil` work is refused even when an execution context is supplied. Native B execution remains responsible for dispatch checks and source-free settlement of known incurred usage. Campaign revocation can withhold returned metadata or prevent creative publication without undoing already recorded sponsor costs.
