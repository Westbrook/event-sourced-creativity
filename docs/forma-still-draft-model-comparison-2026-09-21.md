# Forma and Still: Draft image model decision

Researched September 21, 2026 EDT / September 22 UTC. Documentation, existing evidence and a read-only production configuration audit; no new paid generations.

**Recommendation: retain the current Ideogram Draft route for now; make GPT-image-2.5 Flare the first candidate for a controlled replacement evaluation.** Flare has the stronger documented fit for fast everyday generation and broader image inputs. Sunburst fits precision editing and finished work. Neither provider documentation nor the retained application benchmark establishes that Flare is faster or better than Ideogram Fast on these workloads. Low-quality GPT-image-2.5 can be cheaper than the current expanded Ideogram request; compare complete request costs before deciding.

## What “Draft” currently means

“Draft” is a product label for `purpose=ideate` **or** `quality=low`, not one model. [Label implementation](/Users/westbrook/Documents/repos/codex/src/model/events.ts:158).

Production environment revision 13 and the local configuration select `FORMA_IMAGE_PROVIDER=fal-ideogram`; production explicitly sets `FAL_IMAGE_PREVIEW_MODEL=ideogram/v4/fast`. Thus ordinary lightweight Forma drafts use **Ideogram V4.0q Fast**, `ideogram/v4/fast`, with `BALANCED` rendering and `Medium` prompt expansion. A single reference instead selects `ideogram/v4/image-to-image`; complex material studies select standard `ideogram/v4`; multiple references or WebP select OpenAI. These exceptions matter when measuring “Draft” performance. [Selector](/Users/westbrook/Documents/repos/codex/worker/image-adapter-selection.ts:8), [endpoint and expansion rules](/Users/westbrook/Documents/repos/codex/worker/fal-image-adapter.ts:59).

Still’s native image jobs already force OpenAI for new preview, generate, prompt-fan, and render-document admissions outside the separate output-preparation route. Production explicitly pinned `OPENAI_IMAGE_MODEL=gpt-image-2`; its GPT-image drafts therefore move to Sunburst when that runtime setting and the verified code are published. They do not inherit Forma’s Fal default. Retained jobs keep their admitted route. [Still admission policy](/Users/westbrook/Documents/repos/codex/worker/document-jobs-api.ts:4127), [policy helper](/Users/westbrook/Documents/repos/codex/worker/still-image-policy.ts:4). The non-secret production model/provider settings were verified through Sites; credentials were not disclosed.

## Product flexibility and quality evidence

The application supports prose, bullets, JSON, and XML as **text representations**, not separate native modalities. Ideogram’s adapter reduces them to a 4,000-character provider prompt and expands it. OpenAI accepts prompts up to 32,000 characters. Native GPT capabilities also include PNG/JPEG/WebP, transparency, and masks. The current direct Image API integration sends text and reference bytes; it does not send masks or expose every provider quality/background control. A model change alone does not add those UI features. [Ideogram contract](/Users/westbrook/Documents/repos/codex/docs/adapters/fal-ideogram-v4.md:19), [GPT request construction](/Users/westbrook/Documents/repos/codex/worker/openai-adapter.ts:470), [OpenAI generation API](https://developers.openai.com/api/reference/resources/images/methods/generate), [edit API](https://developers.openai.com/api/reference/resources/images/methods/edit).

The retained August 21 qualification reports **20.427 seconds mean Fal latency versus 58.210 seconds** for the pre-2.5 OpenAI baseline. Fal produced 43/50 usable outputs, including 10/10 reference cases; mean instruction adherence was 3.74 versus 4.04, and the evaluator preferred OpenAI in 33/50 pairs. This supports retaining a useful existing route while investigating alternatives. It mixes Fast, standard, and editing requests and provides no Sunburst/Flare comparison or production percentile guarantee. [Retained result](/Users/westbrook/Documents/repos/codex/docs/evaluations/ideogram-adapter-cycle-5-outcome.md:25), [detailed evidence](/Users/westbrook/Documents/repos/codex/worker/image-adapter-evaluation-evidence.ts:242).

Before replacing Draft, compare all three on the same lightweight prompts and dimensions, plus reference and complex-material strata; test Flare at low and medium. Measure end-to-end p50/p95, first usable preview, actual cost per accepted result, retries, exact text, spatial constraints, and reference preservation. Keep canonical prompts and blind judgments. **Favor Flare if it matches accepted quality and responsiveness at lower complete cost; favor Sunburst where edit fidelity is the deciding requirement.** No new benchmark was run and no Draft-provider switch is implied by this recommendation.
