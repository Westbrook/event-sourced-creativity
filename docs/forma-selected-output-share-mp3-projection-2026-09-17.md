# Dormant Stable Audio MP3 public copy

This new Worker helper produces a separate, metadata-free PCM16 WAV from an exact owned MP3. It closes the codec feasibility gap for the native 20-second Stable Audio recipe without changing the existing private MP3 inspector, accepted WAV gate, producer, current media, or public-sharing routes. No production entry point calls the helper. It does not create a share or confer publishing authority.

The source and public representation have separate hashes. Original MP3 frame boundaries alone cannot prove privacy: the preserved allocation-only counterexample carries a private marker inside ignored entropy bits. The new helper actually decodes the recording in the trusted Worker and writes only a fixed WAV header and decoded samples. A valid gapless envelope around the marker and zeroed controls produces identical WAV bytes. This proves the tested metadata/payload exclusion, not absence of covert information in PCM or a semantic privacy judgment.

## Fixed contract

`projectSelectedOutputShareMp3(bytes, expected, signal)` accepts an ordinary, nonshared Uint8Array, a closed data record containing exact SHA-256, length, `audio/mpeg`, and `forma.audio.instrumental-20@1`, and a native AbortSignal. It captures bytes before any await. The recipe declaration is not native authority; a future host must obtain these facts from its current native Audio custody witness.

Only the explicitly versioned `selected-output-share-stable-mp3-pcm16-v1` representation is produced. The successful opaque witness binds source hash/length/type, projection version, decoder hash, public WAV hash/length/type, sample rate, channels and sample count. `copySelectedOutputShareMp3Bytes` recognizes only the exact locally created witness and returns a separate copy. A serialized or forged result cannot retrieve bytes. The unchanged WAV gate independently qualifies the resulting container and owns its bytes.

The envelope is a conservative MPEG-1 Layer III subset: no CRC/free format/emphasis/dual-channel mode, fixed sample clock and channel count, mono or stereo (stereo/joint-stereo transitions allowed), 32/44.1/48 kHz, at most 1,000,000 source bytes, and at most 20 seconds of decoded PCM. ID3 v2.3/v2.4 has bounded, recognized, length-delimited frames and no unsupported flags. Its contents are discarded and never passed to the codec or returned. Unknown or ambiguous layouts refuse.

A mandatory Xing/Info frame must have exact physical-frame and byte counts, a recognized LAME/Lavc/Lavf extension, supported revision, and consistent 12-bit delay/padding. Decoder padding must accommodate mpg123's 529-sample decoder delay. Physical frames are bounded from the 20-second output cap plus the full 12-bit delay/padding range, with a hard 842-frame ceiling. Exact-end, count, duration and post-decode sample checks reject truncated whole-frame streams and contradictory gapless declarations. The parser is not an entropy privacy gate; decoding and a fresh fixed WAV representation provide metadata separation.

PCM conversion is deterministic: nonfinite values and samples outside [-1,1] refuse; otherwise signed PCM16 uses `Math.round(sample * (sample < 0 ? 32768 : 32767))`. There is no resampling, downmixing, loudness normalization or truncation to satisfy limits. Valid MP3 overshoot consequently remains a supported-subset limitation. Quantization is explicit; byte-exact PCM agreement with other decoders is not claimed. Listening quality, rights, watermark presence and semantic privacy are not assessed.

## Worker ownership and resource limits

The pinned static WASM module has SHA-256 `f0e9e8848367320ccb757e4092f0d6809668cfe38f43139d47b447151d7dff6b` and fixed memory of 259 pages (16,973,824 bytes). The Worker instantiates it directly; there is no runtime compile, client PCM, Web Audio, external decoder service, arbitrary module parameter, filesystem or network operation.

Each isolate has one reusable native instance and one projection lease. Concurrent calls refuse instead of queuing. Each bounded MPEG frame feeds at most 1,441 bytes and permits at most four native read calls, with bounded sample output. Every 16 frames, execution yields so abort/deadline events can run. Five seconds is an observable asynchronous deadline, not an ability to interrupt synchronous WASM. Structural frame, sample and call limits plus platform CPU enforcement bound uninterrupted work. Local timing is not production or physical-device performance evidence.

The pinned C wrapper ignores its output-size argument. Its full output allocation is retained and its ABI is checked. Initialization is attempted at most once. Normal partial allocation and constructor errors release owned allocations; the destructor frees its own struct exactly once. Native allocation/feed/read traps quarantine the instance, wipe its complete fixed heap, and prevent reuse. Ordinary decode refusals, sample-range refusals, cancellation and timeout close the decoder and zero adapter-owned input/output ranges; a later valid operation can reuse the instance. Quarantining avoids trusting native state after a trap.

The active operation owns at most 1 MB of captured source, one 3,840,044-byte WAV under construction, and the accepted WAV gate's independent owned copy, besides the fixed decoder heap and small frame/metadata records. Crypto/runtime scratch space, the caller's own input, and copies deliberately retained by the caller are additional; this is not a claim that the entire Forma isolate's memory is exactly that sum. The helper avoids a whole-recording Float32 array and repeated 16 MB instances. Returned witnesses and copied files remain the host's lifetime responsibility.

## Focused qualification

- 39 pure envelope cases cover valid layouts, exact clocks/counts/end, metadata flags, contradictory/truncated gapless claims, larger valid encoder padding, and one-sample duration boundaries.
- Six actual local-workerd groups cover deterministic synthetic mono/stereo WAV hashes, ignored-payload equality, source capture/mutation, closed facts/brands, opaque-copy ownership, concurrency, abort, a real five-second timeout, and later reuse.
- Eleven actual local-workerd fault groups cover initialization/partial allocation/constructor failures, bounded read loops, native traps, clock/sample overflow, nonfinite values and overshoot. The fault ports wrap the real compiled codec; they are not additional live-provider journeys.
- Independent review separately ran seven native-export fault-port groups and one actual mid-decode cancellation scenario. Cancellation became observable after real PCM production and one 16-frame batch; buffers were zeroed and subsequent decoding reused the same native instance. These overlap supplier behaviors and are not summed as extra distinct product cases.
- Actual Vite 8.0.13/Cloudflare 1.37.1 packaging produced a separate static 99,479-byte WASM module with the exact hash. Its built Worker ran both synthetic fixtures. The client artifact contained neither the decoder nor its source; no app config or package change was needed.
- The root-authorized, previously accepted historical original MP3 was verified read-only through the frozen Vite-built Worker: 494,586 bytes, source SHA-256 `00cfda61443e6ae4279d874acb0ed443c9e3e911b680f9e9743f8e152ee11952`. It produced 882,000 PCM frames at 44.1 kHz stereo (20 seconds), public WAV hash `041a1fa7c2915a041da04539ee3178d382a0c0218a80f6ed389aaa6a1aa23023`. Original hash/size/mtime remained unchanged; no real source or decoded WAV was persisted, uploaded or published. This is historical revision 0 compatibility, not the current authored 19-second WAV.

Synthetic reference comparison against installed FFmpeg asserts matching sample counts and a maximum difference of one PCM16 unit for the two non-silent fixtures; zero/marker controls match exactly. Existing provider acceptance is reused. No provider request, charge, hold, generated output, live audience or retained media was changed.

Historical failures remain in the evidence packet: initial wrong extraction import, local-listener sandbox refusal, upstream source-notice filename assumption, original unasserted fidelity statistic, a scoped upstream-style lint issue, a stale independent fault-test expectation after the trap fix, and an impostor-input refusal initially classified as decode failure. Corrections and predecessor receipts are preserved. None invalidates the eight accepted journeys.

## Source and integration boundary

`worker/vendor/mpg123` contains the exact binary, complete pinned codec source archive, selected wrapper/build source archive, extraction source, source manifests, notices, and offline reproduction tools. The binary extraction is independently reproducible. Compilation of the C sources into byte-identical WASM is **not** established. See `REBUILD.md` for the exact source/toolchain pins and missing original generated-build records. The wrapper declares MIT; libmpg123 is LGPL 2.1. Emscripten/runtime and extraction-tool notices are included; the whole artifact is not described as MIT-only.

Next integration belongs to the native media-sharing owner. That host must bind the opaque projection to the same current Audio Document/revision/source witness, maintain separate source/public identities through review and publication, and recheck current custody before serving the selected public WAV. It must preserve existing review/export and retention requirements. The helper is dormant and does not approve sharing or replace those checks. Ordinary private editing, restoring, reopening and downloading continue to use their existing representations.
