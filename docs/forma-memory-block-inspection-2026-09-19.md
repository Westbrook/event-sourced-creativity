# Native document block inspection and private consumption v5

Local feature-branch continuation of MEM-003. No production change, migration,
real provider call, enrollment, budget change or hosted schedule registration.

## Implemented

Opening the actual Document block controls can now emit one instrumentation
receipt. Selection, closing controls, hidden/stale/disconnected views, changed
routes or source owners do not emit it. The optional write never blocks ordinary
inspection or retries an uncertain commit. No block text is sent in this request.

The isolated native writer checks the authenticated reader, exact document and
project custody, complete current native block-field event IDs and historical
version hash. Publication repeats source/access proofs around an atomic private
event and governed sidecar/head update. It does not grant authoring, learning,
provider or enrollment authority. Other actors receive a restricted placeholder.

Consented scheduled capture stores references and original lifetime ceilings,
resumes pages of at most 32 inspections alongside artifact observations without
skipping either producer, and rolls back the cursor on failed source publication.
Derivation independently certifies retained inspection receipts and original
field versions. Only typed actions enter the model input, never block prose as a
human quotation. Complete supporting-event dependencies withdraw derived payloads
on erasure; financial usage remains independent of privacy deletion.

The private inspector explicitly negotiates **consumption v5**. It joins navigation,
artifact viewing and certified block-control openings in a separate source map,
with source version hashes, unavailable counts and the existing parent display
lease. English, French, Arabic and Japanese labels distinguish opening controls
from attention, comprehension or preference. Older v1–v4 contracts are unchanged.

## Boundaries and capacity

This supports document-local native block-field histories already covered by the
block certifier. Library/canvas placements, ambiguous or unsupported source-event
histories and cross-document source authority remain unavailable, not guessed.
The block controls are not a reading-completion sensor. No raw inspection receipt
is silently added to legacy assistant answer origins or exports.

Three simple original-plus-block windows qualify at 48 D1 calls. Combining block
inspection, artifacts and approved-copy evidence uses an explicit whole-window
capacity boundary: at most two free Creator windows (45 calls), one paid Creator
window (33), and one mixed-producer anchor (32/33). This is incomplete bounded
history, not lifetime recall; older manifests keep their original contracts.
