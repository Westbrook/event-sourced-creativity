# Cross-media deployment evidence — P5 R8

These findings apply to image, video, audio, document and other generation adapters when they rely on exact database schema admission. They establish no generation-quality improvement.

- Match deployment archives to exact source and preserve raw catalog definitions. A raw-SQL mismatch is not evidence of a particular missing table or migration.
- Exercise relevant migration machinery in local tests. Directly executing migration statements omits bookkeeping that a migrator can create; the local Drizzle result is not proof of native Sites behavior.
- Treat bounded table listings as incomplete until their limit/pagination contract and completeness are established.50 names cannot prove that two trailing tables are absent.
- A fixed, bounded, owner-only metadata read can resolve schema uncertainty without executing providers, reading user records or creating a test run. Record raw differences first; never hide changed constraints/indexes/triggers with blanket canonicalization.
- Native admission, deployed identity/runtime, actual application schema/holds/custody, financial authority and media quality are distinct evidence. Keep each qualification separate.
