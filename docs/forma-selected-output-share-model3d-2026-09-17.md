# Exact-byte GLB qualification for selected-output sharing

This dormant pure helper qualifies a deliberately limited self-contained GLB subset. It adds no caller, route, schema, UI, provider request or publishing authority. Native private GLB readers are unchanged. A native-format acceptance or a static-preview acceptance has never implied approval of hidden metadata for selected-output sharing.

`qualifySelectedOutputShareModel3d(bytes, { sha256, byteLength })` captures an ordinary, nonshared `Uint8Array` before its first asynchronous operation. The expected fields are closed data properties. It reuses `validateModel3dAsset` for bounded GLB framing, self-contained resources, references and geometry, then the native `qualifyStaticModel3dAsset` for the selected rooted static assembly and full digest. Both the expected SHA-256 and exact length must match. The 64 MiB native byte limit, 2 MiB JSON limit, node/accessor limits, two-million-vertex budget and native component-read bounds remain effective. The native geometry validation runs twice because the static qualification owns its own validation and byte snapshot; this first unused helper favors reuse of those boundaries over extracting them.

The supported subset is explicit:

- Compact JSON equal to its parsed `JSON.stringify` representation, followed only by the required zero-to-three GLB space-padding bytes. This rejects duplicate properties, alternate escaped representations and ignored whitespace payloads. Pretty-printed or otherwise valid noncanonical JSON remains unavailable; the helper never rewrites it.
- One self-contained BIN and one static rooted scene. All nodes and meshes must belong to that scene. A grouping node must lead to mesh geometry. Matrix transforms are unsupported because loader decomposition can discard matrix cells; explicit translation, scale and unit-quaternion rotation are supported. Unit checks allow `0.00001` error in squared length for floating-point representations.
- Uncompressed triangle primitives with float `POSITION`, optional float unit `NORMAL`, and optional float `COLOR_0` in the glTF zero-to-one range. Positions have exact computed bounds. Optional unsigned 8-, 16- or 32-bit indices must consume every vertex in each primitive. Disjoint primitive index sets sharing a larger vertex pool are outside this first subset.
- One tightly packed accessor per view, with no interleaved stride or nonzero accessor offset. Every accessor, view and material must be used. Sorted views cover the entire declared BIN payload with only exact zero alignment padding between them; native validation checks the final zero GLB padding. Overlaps, unreferenced resources, unused vertex payload, inflated views and opaque tails refuse.
- Closed numeric core PBR material factors, emissive factors, double-sided rendering and validated alpha-mode/cutoff settings. Arbitrary names, asset generator/copyright, extras, extensions, unknown/custom attributes, URI/data URI resources and arbitrary JSON strings refuse at every supported object level.

Images, textures, samplers, camera resources, animations, skins, morph targets, matrix transforms, extension data, compressed meshes and other GLB export packages remain unsupported. In particular, this untextured policy cannot imply that an embedded PNG/JPEG/WebP is suitable for sharing. A later textured increment needs exact referenced-image qualification and full dependency/byte accounting; it must not expose an original reference PNG or a retained asset list by default.

The frozen result contains only the gate policy, native static policy, MIME, hash and length. Its locally owned bytes are held in a `WeakMap`; `copySelectedOutputShareModel3dBytes` returns a fresh copy only for the exact local qualification object. Serialized, spread, proxied or forged facts cannot retrieve bytes. Refused copies are cleared. Neither success nor byte access proves ownership, current revision, source/receipt custody, audience, publication consent, semantic object count, visible artistic content, rights or absence of numerical steganography. Those are separate selected-share review and authority responsibilities. No normalization, conversion, metadata stripping, model replacement or generation occurs.

## Verification and remaining integration

The new focused suite uses synthetic triangle and GLB chunk construction from the existing native model tests. It covers exact byte/hash custody of the local snapshot, one-root multiple-mesh previews, indexed and attributed geometry, strict metadata closure, resource and binary reachability, duplicate/escaped JSON, malformed geometry, invalid native loader semantics, mutable caller inputs, forged results and finite byte limits. One case passes the exact qualified bytes through the actual installed Three.js GLTFLoader and verifies its static mesh, index, vertex and material result. This is loader and native static-policy coverage, not a rendered GPU, physical-device or artistic-quality claim. It does not reopen or regenerate any of the eight accepted provider outputs.

Independent review found five pre-release cases that the initial gate accepted: a reachable empty leaf with unused transforms; a matrix containing four non-affine cells discarded by the actual installed Three.js loader; a nonunit quaternion; nonunit normals; and out-of-range float colors. The five regression tests were executed red before the gate was narrowed. The matrix and empty-branch cases concerned ignored payload; quaternion, normal and color checks concern supported numeric rendering semantics. The original native reader is deliberately unchanged. Initial and red logs remain in the evidence packet. The initial `npm run check:types` attempt failed because that script does not exist; the repository's `tsc --noEmit` check was then run successfully. No failed command is counted as successful validation.

This helper alone does **not** complete selected 3D sharing. The next independently reviewed work must bind an ordinary-personal current native GLB selection and its completion/edit/reset witness, explicitly review its small public manifest and title, serve only exact qualified bytes through a share-scoped asset handle, and recheck token lifetime, current custody and publishing policy before responding. Routes, lifecycle/schema extensions and explicit UI remain with their respective owners. Textured and other unsupported formats remain a coverage gap, not a claim of completion or an automatic release prerequisite.
